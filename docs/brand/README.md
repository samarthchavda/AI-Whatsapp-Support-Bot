# Kwickbot brand — Block K

A **k** built from three rounded blocks: the stem is the store, the pistachio
block is the AI, and the lower block (always on top) is the team taking over.

## Files

| File | Use |
|---|---|
| `svg/kwickbot-mark.svg` | Main mark, for light backgrounds |
| `svg/kwickbot-mark-reversed.svg` | Mark for dark backgrounds |
| `svg/kwickbot-mark-mono.svg` | One-colour mark (uses `currentColor`) |
| `svg/kwickbot-logo.svg` / `-reversed.svg` | Mark + wordmark. The wordmark is live text in Space Grotesk; convert it to outlines in Figma/Illustrator before print |
| `svg/kwickbot-app-icon.svg` | Rounded app icon, deep olive tile |
| `png/kwickbot-logo-1200.png` / `-reversed-1200.png` | Logo with exact wordmark, transparent background |
| `png/kwickbot-mark-1024.png`, `-512.png`, `-reversed-512.png` | Mark only, transparent background |
| `png/kwickbot-app-icon-512.png`, `-192.png` | Web app manifest icons (`logo512.png`, `logo192.png`) |
| `png/apple-touch-icon-180.png` | iOS home-screen icon |
| `png/whatsapp-profile-640.png` | WhatsApp Business profile photo (safe inside the circle crop) |
| `png/favicon-16/32/48.png`, `favicon.ico` | Browser tab icons |

## Colours

| Name | Hex | Use |
|---|---|---|
| Pistachio | `#B9DB97` | Brand colour, AI block on dark |
| Leaf | `#8DBF64` | AI block on light backgrounds |
| Olive | `#3D5A22` | Mark, primary buttons |
| Deep | `#2A3D18` | Dark surfaces, app icon |
| Mist | `#F5F8EF` | Page background, mark on dark |
| Ink | `#1D2A13` | Text, one-colour logo |

## Type

- Wordmark: **Space Grotesk SemiBold**, lowercase, −3% letter-spacing.
- Website and app UI: **Plus Jakarta Sans**.

## Rules

- Clear space around the logo = height of one arm block.
- Minimum size: mark 16px, full logo 96px wide.
- Don't stretch, rotate, recolour (no blue), or put olive on olive.

The full guide is the "Block K · Brand guide" board on the Brand page of the design canvas.
